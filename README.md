# Leader Talk

Practice sounding calm, confident, formal and respectful in workplace conversations,
and learn to spot what weakens a reply. No AI: feedback comes from transparent rules
and published communication research.

This `main` branch holds the first prototype (a local Python app):

```bash
python3 app.py   # then open http://127.0.0.1:8765
```

The phone version (an installable offline web app) arrives in the phase pull requests.
